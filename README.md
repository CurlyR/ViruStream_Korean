# ViruStream 한국어 패치 v1.0.1

한글 번역: **컬리비**

## 지원 버전

- Windows / Steam판 ViruStream
- 확인한 게임 빌드: **25876512**
- 게임 본편을 설치한 상태에서 사용합니다. 다른 빌드의 파일은 설치 도구가 거부합니다.
- 별도 Python, Unity, 번역 플러그인 설치는 필요하지 않습니다.

## v1.0.1 변경 사항

- 2026년 10월 12일 게임 업데이트(빌드 25876512)에 대응했습니다.
- 공식 업데이트로 설정 화면에 추가된 게임 로고를 보존했습니다.
- 기존 한국어 퍼즐, 자막 영상, 뒷면 힌트와 번역 크레딧을 유지했습니다.
- 업데이트 후 남은 이전 패치 파일은 기존 원본 백업을 검증하여 재설치합니다. 원본 백업이 없으면 Steam 무결성 검사 후 설치하세요.
- 이번 빌드는 파일 구조와 설치·복구를 검사했습니다. 새 빌드 전체 플레이 검수는 아직 완료하지 않았습니다.

## 설치

1. 게임을 완전히 종료합니다.
2. Steam 라이브러리에서 ViruStream을 우클릭하고 **관리 → 로컬 파일 탐색**을 엽니다.
3. **ViruStream.exe와 ViruStream_Data가 함께 있는 폴더**를 찾습니다. 폴더 안에 ViruStream 폴더가 한 번 더 있다면 그 안을 확인하세요.
4. 압축을 풀어 나온 `ViruStream_Korean_Patch_v1.0.1` 폴더를 그곳에 넣습니다.
5. 패치 폴더 안의 **install.cmd**를 실행합니다.
6. ‘한국어 패치 설치 완료’ 메시지를 확인한 뒤 Steam에서 게임을 실행합니다.

패치 폴더를 다른 위치에 풀었다면, 설치 도구가 물어볼 때 ViruStream.exe가 있는 폴더의 전체 경로를 입력하세요. 압축파일 안에서 바로 실행하지 마세요.

설치 도구는 버전과 파일을 먼저 검사하고, 원본을 `KoreanPatch_Backup/25876512`에 백업합니다. 게임 설치 위치에 맞춰 영상·정답표 링크도 설정합니다. 직접 payload 파일만 복사하면 링크가 설정되지 않습니다.

## 포함된 내용

- 게임 내 한국어 대사·메뉴·시작 안내 및 한글 글꼴
- 일본어 이미지와 한국어 문자 퍼즐 현지화
- ClockOut 상점 영상 한국어 자막
- H 단서 영상의 로컬 재생·한국어 자막·게임과 연결되는 이미지 조각
- 한국어 정답표와 검색 방법 안내
- 원본 3D 평면을 사용하는 한국어 뒷면 힌트
- 엔딩 크레딧 ‘한글 번역 / 컬리비’

게임 화면 아래의 **영상·단서**, **정답표**를 누르면 기본 브라우저에서 로컬 페이지가 열립니다. 영상과 퍼즐 진행에 필요한 자료는 인터넷 없이 볼 수 있습니다. 페이지의 YouTube 원본 링크를 직접 누를 때에는 인터넷이 필요합니다.

## 원본으로 되돌리기

1. 게임을 종료합니다.
2. 패치 폴더의 **restore.cmd**를 실행합니다.
3. ‘원본 복구 완료’ 메시지를 확인합니다.

백업 폴더는 삭제하지 마세요. 복구 후에도 보조 페이지와 백업은 남습니다. 백업을 잃어버린 경우 Steam의 **속성 → 설치된 파일 → 게임 파일 무결성 검사**로 게임 파일을 복구할 수 있습니다.

## 업데이트·설치 위치 변경

- Steam 업데이트나 무결성 검사로 패치가 해제될 수 있습니다.
- 새 빌드는 이 패치와 호환되지 않을 수 있습니다. 버전 검사에 실패하면 강제로 덮어쓰지 마세요.
- 게임 폴더를 이동한 경우 같은 빌드에서 install.cmd를 다시 실행하면 로컬 링크를 새 경로로 설정합니다.
- 설치 후 `korean_clues` 폴더를 옮기거나 삭제하지 마세요. 열려 있던 보조 페이지는 새로고침하세요.

## 문제 해결

- **게임을 종료하라는 메시지:** 실행 중인 ViruStream을 닫고 다시 설치합니다.
- **ViruStream.exe를 찾지 못함:** 실행 파일이 있는 폴더를 정확히 선택합니다.
- **지원하지 않는 게임 파일 / 파일 검증 실패:** 게임 버전이나 다른 패치 여부를 확인하세요. Steam 무결성 검사 후 지원 빌드에서 다시 설치합니다.
- **쓰기 권한 오류:** 게임 폴더의 쓰기 권한을 확인하세요. 필요하면 install.cmd를 우클릭해 관리자 권한으로 실행합니다.
- **영상·정답표가 안 열림:** install.cmd를 다시 실행하세요. 게임 폴더의 `korean_clues/video-clues.html`과 `answer-sheet.html`을 직접 열 수도 있습니다.

제보할 때는 게임 빌드, 문제 화면, 발생 단계와 설치 도구의 오류 메시지를 함께 알려 주세요.

## 배포본 구성

- `install.cmd` / `restore.cmd`: 설치·복구 실행 파일
- `patch.ps1`: 원본 백업, 버전 검사, 경로 설정 및 복구 도구
- `payload`: 적용할 한국어 패치 데이터
- `korean_clues`: 오프라인 영상과 퍼즐 보조 페이지
- `package.json`: 파일 검증 정보
- `README.md`: 이 안내문

세이브 데이터, 게임 실행 파일, 계정 정보, 개발 도구, 제작 중간 파일은 포함하지 않았습니다. 설치 도구는 세이브 데이터를 수정하지 않습니다.
